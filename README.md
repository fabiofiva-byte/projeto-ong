# 🚀 Projeto ONG - Educação e Inclusão

## 📋 Sobre o Projeto
Este projeto foi desenvolvido como parte do desafio prático da disciplina de Design Profissional (Ciência da Computação). O objetivo principal é transformar uma interface estática em uma aplicação dinâmica e interativa, simulando funcionalidades de uma aplicação real.

A aplicação permite que os usuários conheçam as ações sociais da ONG Educação e Inclusão, interajam com a plataforma navegando pelos projetos e utilizem formulários validados para simular engajamento e contato.

## 💻 Tecnologias Utilizadas
* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização visual e responsividade.
* **JavaScript:** Manipulação do DOM, interatividade e tratamento de eventos do usuário.
* **Local Storage:** Armazenamento de dados no navegador para simular um banco de dados local.

## ⚙️ Funcionalidades Implementadas
- [x] Interface estática convertida para dinâmica via JavaScript.
- [x] Validação de formulários e resposta a ações do usuário (Event Listeners).
- [x] Manipulação do DOM para exibição de mensagens e atualização de dados na tela.
- [x] Uso de Local Storage para persistência de dados básicos.

## 🚀 Como executar o projeto
1. Faça o clone deste repositório:
   ```bash
   git clone https://github.com/fabiofiva-byte/projeto-ong.git
   ```
1. Abra a pasta do projeto no seu computador.

2. Para editar o código, abra os arquivos no Bloco de Notas.

3. Para ver a aplicação rodando, dê um duplo clique no arquivo index.html para abri-lo no navegador.
